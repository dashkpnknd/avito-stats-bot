# Avito Stats Bot

Telegram-бот для автоматической отправки аналитики Avito в клиентские чаты.

## Что делает

- Отправляет отдельные ежедневные (за вчера), еженедельные (за прошлую полную неделю) и ежемесячные (за прошлый месяц) отчёты.
- Для каждого проекта включает и выключает эти три вида отчётов в приватной панели бота. Новым проектам включены ежедневный и еженедельный отчёты; месячный выключен.
- Берёт `uniqViews` и `uniqContacts` через API Avito, сравнивает их с прошлым сопоставимым периодом и отправляет в клиентский чат.
- Хранит ключи Avito в зашифрованном виде, ограничивает управление списком `ADMIN_IDS`, ведёт журнал доставок и не повторяет уже отправленный отчёт за период.
- Уведомляет администраторов о проблемах с Avito API или Telegram после трёх попыток отправки.
- В каждый отчёт добавляет остатки «Кошелёк» и «Аванс» на момент формирования сообщения и их сумму.
- Проверяет общий баланс каждого проекта (кошелёк + аванс). При остатке ниже 3 000 ₽ отправляет клиенту предупреждение с тегом и не спамит: повтор — не чаще заданного интервала.
- Отправляет одно общее уведомление обо всех новых или повторно требующих внимания низких балансах в отдельный чат авитологов.

Дополнительные метрики не включаются в шаблон, пока API Avito их реально не вернёт: отчёт не должен показывать вымышленные нули.

## Развёртывание

1. Создайте отдельного системного пользователя `avito-bot` и каталог `/opt/avito-stats-bot`.
2. Склонируйте репозиторий, создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `/etc/avito-stats-bot.env`, заполните переменные и назначьте файлу права `600`.
4. Установите `avito-stats-bot.service` в `/etc/systemd/system/`, затем выполните `systemctl daemon-reload` и `systemctl enable --now avito-stats-bot`.
5. Напишите боту `/start` с Telegram ID, указанного в `ADMIN_IDS`. Добавьте бота в клиентский чат с правом отправки сообщений, затем добавьте проект через панель.

## Настройка предупреждений о балансе

1. Создайте отдельную группу или канал авитологов, добавьте туда бота с правом отправки сообщений и получите его ID командой `/get_id`.
2. Укажите этот ID в `LOW_BALANCE_ALERT_CHAT_ID` в `/etc/avito-stats-bot.env`.
3. При добавлении проекта укажите тег клиента (`@username`) либо пропустите его. Его можно изменить кнопкой «Тег клиента» в настройках проекта.
4. В карточке проекта есть отдельный переключатель «Контроль баланса». Он включён по умолчанию и работает независимо от включённых отчётов.

`LOW_BALANCE_CHECK_MINUTES` задаёт интервал проверки (по умолчанию 60 минут), `LOW_BALANCE_REMINDER_HOURS` — через сколько часов повторять клиенту предупреждение, если баланс так и не пополнен (по умолчанию 24 часа).
